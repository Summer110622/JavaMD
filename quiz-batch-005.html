interface / default

Q96. 出力は？

interface Named {
    default String name() { return "I"; }
}
class Parent {
    public String name() { return "P"; }
}
class Child extends Parent implements Named { }
System.out.println(new Child().name());
A. I
B. P
C. defaultメソッドが競合してコンパイルエラー
答え・解説
B。P。 クラスから継承した具体メソッドは、interfaceのdefaultメソッドより優先されます。この場合Child側でオーバーライドしなくてもParent.name()が使われます。
override / checked exception

Q97. 次のChild.load()は有効？

class Parent {
    void load() throws java.io.IOException { }
}
class Child extends Parent {
    @Override
    void load() throws Exception { }
}
A. 有効
B. コンパイルエラー
答え・解説
B。 オーバーライド側は、親メソッドより広いchecked例外を宣言できません。ExceptionはIOExceptionより広いため不正です。
interface / modifier

Q98. 次の実装はコンパイルできる？

interface Worker {
    void work();
}
class Job implements Worker {
    protected void work() { }
}
A. できる
B. できない
答え・解説
B。 interfaceの抽象メソッドは暗黙にpublicです。実装時にprotectedへアクセス範囲を狭めることはできません。
constructor / access

Q99. 次のChildはコンパイルできる？

class Parent {
    private Parent() { }
}
class Child extends Parent { }
A. できる
B. できない
答え・解説
B。 Childのデフォルトコンストラクタは暗黙にsuper()を呼びますが、Parent()はprivateなのでサブクラスから呼び出せません。
this / constructor

Q100. 次のコードはどうなる？

class Pair {
    Pair() { this(1); }
    Pair(int n) { this(); }
}
A. 正常にコンパイル
B. コンパイルエラー
C. 実行時にStackOverflowError
答え・解説
B。 コンストラクタ同士がthis(...)で循環しており、再帰的コンストラクタ呼び出しとしてコンパイル時に拒否されます。
static / method hiding

Q101. 次のコードはコンパイルできる？

class Base {
    static void ping() { }
}
class Child extends Base {
    void ping() { }
}
A. できる
B. できない
答え・解説
B。 親のstaticメソッドと同じシグネチャを、子でインスタンスメソッドとして宣言することはできません。staticなら隠蔽、instanceならoverrideですが、両者を混在させられません。
HashMap / putIfAbsent

Q102. 出力は？

Map<String,Integer> m = new HashMap<>();
m.put("k", null);
m.putIfAbsent("k", 5);
System.out.println(m.get("k"));
A. null
B. 5
C. NullPointerException
答え・解説
B。5。 HashMap.putIfAbsentは、キーが未登録の場合だけでなく、そのキーの現在値がnullの場合にも値を設定します。
Map / merge

Q103. 出力は？

Map<String,Integer> m = new HashMap<>();
m.put("x", 2);
m.merge("x", 3, Integer::sum);
m.merge("y", 4, Integer::sum);
System.out.println(m.get("x") + ":" + m.get("y"));
A. 2:4
B. 5:4
C. 5:null
答え・解説
B。5:4。 xは既存値2と3をsumして5になります。yは未登録なので、結合関数を使わず4がそのまま登録されます。
TreeSet / navigation

Q104. 出力は？

TreeSet<Integer> s = new TreeSet<>();
s.addAll(Arrays.asList(10, 20, 30));
System.out.println(s.lower(20) + ":" + s.ceiling(21));
A. 10:20
B. 10:30
C. 20:30
答え・解説
B。10:30。 lower(20)は20より小さい最大要素10、ceiling(21)は21以上の最小要素30です。
List / Iterator

Q105. 出力は？

List<String> xs = new ArrayList<>(Arrays.asList("A", "B", "C"));
Iterator<String> it = xs.iterator();
while (it.hasNext()) {
    if (it.next().equals("B")) {
        it.remove();
    }
}
System.out.println(xs);
A. [A, B, C]
B. [A, C]
C. ConcurrentModificationException
答え・解説
B。[A, C]。 Iteratorで走査中に直前の要素を削除する場合はIterator.remove()を使えます。この操作は反復中の安全な削除方法です。
array / covariance

Q106. 次のコードはどうなる？

Number[] a = new Integer[2];
a[0] = Double.valueOf(1.5);
A. 正常に実行
B. コンパイルエラー
C. 実行時にArrayStoreException
答え・解説
C。 Integer[]はNumber[]へ代入できますが、実体の配列型はInteger[]のままです。Doubleを格納しようとすると実行時にArrayStoreExceptionになります。
switch / fall-through

Q107. 出力は？

int n = 2;
int sum = 0;
switch (n) {
    case 1: sum += 1;
    case 2: sum += 2;
    case 3: sum += 3; break;
    default: sum += 10;
}
System.out.println(sum);
A. 2
B. 5
C. 15
答え・解説
B。5。 case 2から開始し、breakがないためcase 3へフォールスルーします。2 + 3 = 5です。
loop / labeled break

Q108. countはいくつ？

int count = 0;
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (i == 1 && j == 1) break outer;
        count++;
    }
}
System.out.println(count);
A. 3
B. 4
C. 6
答え・解説
B。4。 i=0で3回、i=1ではj=0で1回だけ加算し、j=1で外側ループごと終了します。
cast / null

Q109. 出力は？

Object o = null;
String s = (String) o;
System.out.println(s == null);
A. true
B. false
C. ClassCastException
答え・解説
A。true。 nullは参照型へキャストしてもnullのままです。実体がないため、このキャスト自体でClassCastExceptionは発生しません。
boolean / short-circuit

Q110. 出力は？

int n = 1;
boolean r = (n++ == 1) || (++n == 3);
System.out.println(n + ":" + r);
A. 1:true
B. 2:true
C. 3:true
答え・解説
B。2:true。 左辺は後置インクリメントでtrueになり、その時点でnは2です。||は短絡評価するので右辺の++nは実行されません。
instanceof / interface cast

Q111. 2行の出力は？

Object o = new StringBuilder("ab");
System.out.println(o instanceof CharSequence);
CharSequence c = (CharSequence) o;
System.out.println(c.length());
A. true / 2
B. false / 2
C. true / ClassCastException
答え・解説
A。true / 2。 StringBuilderはCharSequenceを実装しています。宣言型がObjectでも実体型に基づくinstanceofはtrueで、キャストも成功します。
Thread / start

Q112. 次のコードはどうなる？

Thread t = new Thread(() -> { });
t.start();
t.join();
t.start();
A. 同じThreadがもう一度開始される
B. 2回目のstart()でIllegalThreadStateException
C. コンパイルエラー
答え・解説
B。 Threadオブジェクトは一度しかstart()できません。終了後でも同じThreadを再startするとIllegalThreadStateExceptionです。
synchronized / instance lock

Q113. instance synchronizedメソッドのロック対象として正しいものは？

class Counter {
    synchronized void add() { }
}
A. Counter.class
B. そのメソッドを呼ばれたCounterインスタンス（this）
C. JVM全体で共通の1つのロック
答え・解説
B。 通常のsynchronizedインスタンスメソッドはthisをモニタとして使います。別インスタンス同士なら同じロックではありません。
synchronized / static lock

Q114. static synchronizedメソッドがロックするものは？

class Store {
    static synchronized void save() { }
}
A. Store.class
B. 呼び出し元のthis
C. 新しく生成されたStoreインスタンス
答え・解説
A。 static synchronizedにはthisがありません。ロック対象はそのクラスのClassオブジェクト、ここではStore.classです。
Thread.sleep / static

Q115. mainが次を実行したとき、sleepするのはどのスレッド？

public static void main(String[] args) throws Exception {
    Thread worker = new Thread(() -> { });
    worker.sleep(50);
}
A. worker
B. mainを実行している現在のスレッド
C. どのスレッドもsleepしない
答え・解説
B。 sleep()はstaticメソッドです。インスタンス経由で呼べてしまいますが、休止するのは呼び出し時点の現在のスレッドです。この例ではmainスレッドです。
