検定チェック

実際の試験問題の転載ではなく、2級で問われやすい論点を基に作った確認問題です。まず答えを決めてから「答え・解説」を開いてください。

interface

Q1. 次のコードはコンパイルできる？

interface Runner { void run(); }
class Dog implements Runner {
    void run() { System.out.println("run"); }
}
A. できる
B. できない
答え・解説
B. できない。 interface の通常の抽象メソッドは暗黙に public abstract。実装側は public void run() とする必要があります。
implements / extends

Q2. 正しい宣言はどれ？

A. class Dog extends Runnable
B. class Dog implements Runnable
C. interface Fast implements Runnable
D. interface Fast extends Runnable
答え・解説
B と D。 class → interface は implements、interface → interface は extends です。
static / this

Q3. 次のコードはどうなる？

class Counter {
    int value;
    static void set(int n) {
        this.value = n;
    }
}
A. 正常にコンパイル
B. this の箇所でコンパイルエラー
C. 実行時例外
答え・解説
B。 static メソッドは特定のインスタンスに属さないため this を使えません。
constructor

Q4. コンパイルできる？

class Food {
    Food(String name) {}
}
class Stew extends Food {
}
A. できる
B. できない
答え・解説
B。 Stew のデフォルトコンストラクタは暗黙に super() を呼びますが、Food に引数なしコンストラクタがありません。
super

Q5. どこが問題？

class Child extends Parent {
    Child(boolean flag) {
        System.out.println("start");
        super(10);
    }
}
A. 問題なし
B. super(...) はコンストラクタ先頭で呼ぶ必要がある
答え・解説
B。 明示的な super(...) / this(...) はコンストラクタ呼出しとして先頭に置く必要があります。
HashMap

Q6. 出力は？

Map<String,Integer> map = new HashMap<>();
map.put("A", 10);
map.put("B", 20);
map.put("A", 30);
System.out.println(map.size());
System.out.println(map.get("A"));
A. 3 / 10
B. 3 / 30
C. 2 / 30
答え・解説
C。2 / 30。 同じkeyへの put は要素追加ではなくvalueの上書きです。
Set

Q7. size はいくつ？

Set<String> set = new HashSet<>();
set.add("A");
set.add("A");
set.add("B");
System.out.println(set.size());
A. 1
B. 2
C. 3
答え・解説
B。2。 Set は重複を保持しません。2回目の add("A") は要素を増やしません。
TreeSet

Q8. 出力は？

Set<String> set = new TreeSet<>();
set.add("C");
set.add("A");
set.add("B");
System.out.println(set);
A. [C, A, B]
B. [A, B, C]
C. 順序は完全に不定
答え・解説
B。 TreeSet は重複を除き、自然順序で並びます。
2次元配列

Q9. 何が表示される？

int[][] data = { {1, 2}, null, {3, 4, 5} };
for (int[] row : data) {
    if (row != null) {
        System.out.println(row.length);
    }
}
A. 2, 0, 3
B. 2, 3
C. NullPointerException
答え・解説
B。2, 3。 外側の拡張forで受け取るのは1行分の int[]。null行はifで除外されています。
boolean

Q10. 出力は？

boolean flag = false;
if (!(flag = false)) {
    System.out.println("true");
}
A. コンパイルエラー
B. true
C. 何も表示されない
答え・解説
B。 flag = false は代入式で、その値はfalse。! でtrueになります。== との見間違いに注意。
instanceof

Q11. 条件式はtrue？

interface Swim {}
class Fish implements Swim {}
class Salmon extends Fish {}
Salmon s = new Salmon();
System.out.println(s instanceof Fish && s instanceof Swim);
A. true
B. false
C. コンパイルエラー
答え・解説
A。true。 Salmon は Fish のサブクラスで、Fish が Swim を実装しているため両方成立します。
Thread

Q12. 新しいスレッドを開始するのはどれ？

A. thread.run()
B. thread.start()
C. Thread.sleep(1000)
D. thread.join()
答え・解説
B。thread.start()。 run() を直接呼ぶだけでは通常のメソッド呼出しです。start() が新しいスレッドを開始します。
List remove

Q13. remove中のループで注意することは？

int i = 0;
while (i < list.size()) {
    if (shouldRemove(list.get(i))) {
        list.remove(i);
        // ???
    }
    i++;
}
A. 削除直後にi++を必ず追加する
B. 削除後は同じindexに次要素が詰められるので、必要ならcontinue等で増分を飛ばす
答え・解説
B。 index i を削除すると次の要素が同じiへ移動します。そこでさらにiを増やすと、その要素を読み飛ばす場合があります。
final

Q14. final class について正しいものは？

A. サブクラスを作れる
B. サブクラスを作れない
C. インスタンス化できない
答え・解説
B。 final class は継承できません。abstract classとは意味が異なります。
short-circuit

Q15. 安全な equals 実装はどちら？

A. id == ((Message)o).getId() && o instanceof Message
B. o instanceof Message && id == ((Message)o).getId()
答え・解説
B。 && は左がfalseなら右を評価しません。先に instanceof で型を確認してからキャストするのが安全です。

学習の使い方: 正解した問題でも「なぜ他の選択肢が違うか」を1文で説明できるか確認すると、正誤問題とコード読解の両方に強くなります。
