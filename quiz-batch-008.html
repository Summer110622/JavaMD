interface / static

Q156. 次のコードはコンパイルできる？

interface Util {
    static void ping() { System.out.print("U"); }
}
class App implements Util { }
App.ping();
A. でき、Uと表示
B. できるが何も表示されない
C. できない
答え・解説
C。 interfaceのstaticメソッドは実装クラスへ継承されません。Util.ping() のように宣言したinterface名から呼びます。
inheritance / private

Q157. 出力は？

class Base {
    private String name() { return "B"; }
    String read() { return name(); }
}
class Child extends Base {
    String name() { return "C"; }
}
System.out.println(new Child().read());
A. B
B. C
C. コンパイルエラー
答え・解説
A。B。 Base.name() はprivateなのでオーバーライド対象ではありません。Base内のread()からはBase自身のprivateメソッドが呼ばれます。
modifier / abstract

Q158. 次のコードはどうなる？

abstract class Task {
    abstract void run();
}
Task t = new Task();
A. 正常にコンパイル
B. コンパイルエラー
C. 実行時にAbstractMethodError
答え・解説
B。 abstractクラスは型として変数宣言には使えますが、new で直接インスタンス化できません。
constructor / override

Q159. 出力は？

class Base {
    Base() { show(); }
    void show() { System.out.print(-1); }
}
class Child extends Base {
    int n = 7;
    void show() { System.out.print(n); }
}
new Child();
A. -1
B. 0
C. 7
答え・解説
B。0。 Baseのコンストラクタから呼んでも、オーバーライドされたChild.show()が動きます。ただしChildのフィールド初期化はsuperコンストラクタ完了後なので、その時点のnは既定値0です。
constructor / this

Q160. 出力は？

class Item {
    int n;
    Item() { this(3); n++; }
    Item(int n) { this.n = n; }
}
System.out.println(new Item().n);
A. 3
B. 4
C. コンパイルエラー
答え・解説
B。4。 引数なしコンストラクタは最初にthis(3)を呼び、nを3に設定した後でn++を実行します。
static / null reference

Q161. 出力は？

class Box {
    static int count = 5;
}
Box b = null;
System.out.println(b.count);
A. 5
B. NullPointerException
C. コンパイルエラー
答え・解説
A。5。 staticフィールドはオブジェクトではなくクラスに属します。参照変数経由の記述は推奨されませんが、この式ではBox.countとして解決されます。
Map / keySet view

Q162. 出力は？

Map<String,Integer> m = new HashMap<>();
m.put("A", 1);
m.put("B", 2);
Set<String> keys = m.keySet();
keys.remove("A");
System.out.println(m.size() + ":" + m.containsKey("A"));
A. 2:true
B. 1:false
C. 1:true
答え・解説
B。1:false。 keySet()はMapと連動するビューです。ビューからキーを削除すると対応するMapエントリも削除されます。
HashSet / equals hashCode

Q163. 出力されるsizeは？

class Key {
    int id;
    Key(int id) { this.id = id; }
    public boolean equals(Object o) {
        return o instanceof Key && ((Key)o).id == id;
    }
    public int hashCode() { return id; }
}
Set<Key> s = new HashSet<>();
s.add(new Key(1));
s.add(new Key(1));
System.out.println(s.size());
A. 1
B. 2
C. 実装依存
答え・解説
A。1。 2つのKeyは別オブジェクトでもequals()がtrueで、同じidから同じhashCode()を返します。HashSetでは同一要素として扱われます。
TreeMap / order

Q164. 出力は？

Map<Integer,String> m = new TreeMap<>();
m.put(3, "C");
m.put(1, "A");
m.put(2, "B");

A. [3, 1, 2]

List / removeIf

Q165. 出力は？

List<Integer> xs = new ArrayList<>(Arrays.asList(1, 2, 3, 4));
xs.removeIf(n -> n % 2 == 0);
System.out.println(xs);
A. [1, 3]
B. [2, 4]
C. ConcurrentModificationException
答え・解説
A。[1, 3]。 removeIfは条件がtrueになる要素を削除します。この場合は偶数2と4が削除されます。
array / Arrays.copyOf

Q166. 出力は？

int[] a = {1, 2};
int[] b = Arrays.copyOf(a, 4);
System.out.println(b[2] + ":" + b.length);
A. 0:4
B. 2:4
C. ArrayIndexOutOfBoundsException
答え・解説
A。0:4。 コピー先を元より長くすると、追加部分は配列要素の既定値で埋まります。intの既定値は0です。
array / enhanced for

Q167. 出力は？

StringBuilder[] a = {
    new StringBuilder("A"),
    new StringBuilder("B")
};
for (StringBuilder s : a) {
    s.append("!");
}
System.out.println(a[0] + ":" + a[1]);
A. A:B
B. A!:B!
C. コンパイルエラー
答え・解説

loop / post increment

Q168. 出力は？

int i = 0;
int sum = 0;
while (i++ < 3) {
    sum += i;
}
System.out.println(i + ":" + sum);
A. 3:6
B. 4:6
C. 4:10
答え・解説
B。4:6。 条件判定でも後置i++は実行されます。本体では1+2+3を加算し、最後のfalse判定でもiが3から4へ増えます。
boolean / &

Q169. 出力は？

int n = 0;
boolean b = false & (++n > 0);
System.out.println(n + ":" + b);
A. 0:false
B. 1:false
C. 1:true
答え・解説
B。1:false。 booleanの&は短絡評価しないため右辺も評価され、nは1になります。左辺がfalseなので全体はfalseです。
cast / runtime

Q170. 次のコードはどうなる？

class A { }
class B extends A { }
class C extends A { }

A x = new B();
C c = (C) x;
A. 正常に実行

Thread / interrupted

Q172. 出力は？

Thread.currentThread().interrupt();
System.out.println(
    Thread.interrupted() + ":" + Thread.interrupted()
);

Thread.currentThread().interrupt();

}

Thread / synchronized

Q174. static synchronizedメソッドが取得するロックはどれ？

class Gate {
    static synchronized void enter() { }
}
A. 呼び出したThreadオブジェクト
B. Gate.classのクラスオブジェクト
C. 新しく生成された専用ロック
答え・解説
B。 static synchronizedメソッドは、そのクラスのClassオブジェクトをロックします。通常のsynchronizedインスタンスメソッドがthisをロックするのとは異なります。
compile error / definite assignment

Q175. 次のコードはコンパイルできる？

int x;
if (args.length > 0) {
    x = 10;
}
System.out.println(x);
A. できる。引数なしなら0と表示
B. できる。引数なしならnullと表示
C. できない
答え・解説
C。 ローカル変数には自動の既定値がありません。ifが実行されない経路ではxが未初期化のままなので、使用時にコンパイルエラーになります。
