override / protected

Q36. 次のコードはコンパイルできる？

class Base {
    protected void ping() {}
}
class Child extends Base {
    void ping() {}
}
A. できる
B. できない
答え・解説
B。 オーバーライドでは、スーパークラスよりアクセス範囲を狭くできません。protected を指定なし（package-private）へ狭めているためコンパイルエラーです。
interface / final

Q37. 次のコードはどうなる？

interface Limits {
    int MAX = 3;
}
class App {
    void change() {
        Limits.MAX = 4;
    }
}
A. MAXが4になる
B. コンパイルエラー
C. 実行時例外
答え・解説
B。 interfaceのフィールドは暗黙に public static final です。定数なので再代入できません。
constructor / this / super

Q38. 出力は？

class A {
    A() { System.out.print("A"); }
}
class B extends A {
    B() { this(2); System.out.print("B"); }
    B(int n) { System.out.print("C"); }
}
new B();
A. ABC
B. ACB
C. CAB
答え・解説
B。ACB。 B() はまず this(2) で B(int) を呼びます。B(int) では暗黙の super() が先に実行されるため、A → C → B の順です。
static / instance

Q39. 出力は？

class Ticket {
    static int total;
    int id = ++total;
}
Ticket a = new Ticket();
Ticket b = new Ticket();
System.out.println(a.id + " " + b.id + " " + Ticket.total);
A. 1 1 1
B. 1 2 2
C. 2 2 2
答え・解説
B。1 2 2。 total は全インスタンスで共有されるstatic変数です。各オブジェクトの id は生成時点の増加後の値を保持します。
HashMap / put

Q40. 2行の出力は？

Map<String,Integer> m = new HashMap<>();
System.out.println(m.put("x", 10));
System.out.println(m.put("x", 20));
A. null / 10
B. 10 / 20
C. null / 20
答え・解説
A。null / 10。 Map.put は、そのkeyに以前対応していたvalueを返します。最初は旧値がないのでnull、2回目は旧値10を返して20へ上書きします。
List / remove

Q41. 出力は？

List<Integer> list = new ArrayList<>(List.of(1, 2, 1));
boolean removed = list.remove(Integer.valueOf(1));
System.out.println(removed + " " + list);
A. true [2, 1]
B. true [1, 1]
C. false [1, 2, 1]
答え・解説
A。 remove(Object) は最初に一致した値を削除し、成功したかをbooleanで返します。remove(int) のindex削除とは別のオーバーロードです。
TreeSet / Comparator

Q42. 出力は？

Set<Integer> s = new TreeSet<>(Comparator.reverseOrder());
s.add(2);
s.add(1);
s.add(3);
System.out.println(s);
A. [1, 2, 3]
B. [3, 2, 1]
C. 挿入順の [2, 1, 3]
答え・解説
B。 TreeSetは指定されたComparatorの順序で要素を保持します。ここでは逆順なので3, 2, 1です。
array / default value

Q43. 出力は？

double[] values = new double[2];
System.out.println(values[0] + ":" + values[1]);
A. 0.0:0.0
B. null:null
C. 未初期化でコンパイルエラー
答え・解説
A。0.0:0.0。 配列要素は型ごとの既定値で初期化されます。double の既定値は 0.0 です。
2次元配列 / loop

Q44. sumはいくつ？

int[][] a = { {1, 2}, {3}, {4, 5} };
int sum = 0;
for (int[] row : a) {
    for (int v : row) {
        if (v % 2 == 1) sum += v;
    }
}
System.out.println(sum);
A. 8
B. 9
C. 15
答え・解説
B。9。 加算されるのは奇数の1、3、5だけです。Javaの2次元配列は各行の長さが異なっていても構いません。
for / continue

Q45. 出力は？

int sum = 0;
for (int i = 0; i < 5; i++) {
    if (i == 2) continue;
    sum += i;
}
System.out.println(sum);
A. 6
B. 8
C. 10
答え・解説
B。8。 continue でi=2の加算だけを飛ばします。0 + 1 + 3 + 4 = 8です。
instanceof / null

Q46. 出力は？

Object o = null;
System.out.println(o instanceof String);
A. true
B. false
C. NullPointerException
答え・解説
B。false。 左辺がnullの instanceof は例外ではなくfalseになります。
cast / runtime

Q47. 次のコードはどうなる？

Object o = Integer.valueOf(7);
String s = (String) o;
System.out.println(s);
A. "7"と表示
B. コンパイルエラー
C. 実行時にClassCastException
答え・解説
C。 ObjectからStringへのキャスト自体はコンパイル可能ですが、実体はIntegerなので実行時に ClassCastException になります。
boolean / short-circuit

Q48. 出力は？

int n = 0;
boolean b = false && (++n > 0);
System.out.println(n + " " + b);
A. 0 false
B. 1 false
C. 1 true
答え・解説
A。0 false。 && は左辺がfalseなら右辺を評価しません。そのため ++n は実行されません。
Thread / join

Q49. 次のmainの出力順として正しいものは？

public static void main(String[] args) throws Exception {
    Thread t = new Thread(() -> System.out.print("A"));
    t.start();
    t.join();
    System.out.print("B");
}
A. 必ずAB
B. 必ずBA
C. ABとBAのどちらもあり得る
答え・解説
A。必ずAB。 join() は対象スレッドの終了を待つため、Aを出力する処理が完了してからmainがBを出力します。
Thread.sleep / checked exception

Q50. 次のメソッドはコンパイルできる？

void pause() {
    Thread.sleep(10);
}
A. できる
B. できない
答え・解説
B。 Thread.sleep は InterruptedException を送出する可能性があります。catchするか、メソッドに throws InterruptedException が必要です。
synchronized / static

Q51. 次のコードはコンパイルできる？

class LockDemo {
    static void work() {
        synchronized (this) {
            System.out.println("x");
        }
    }
}
A. できる
B. できない
答え・解説
B。 staticメソッドには「現在のインスタンス」がないため this を使えません。クラス単位で同期したいなら、例えば synchronized (LockDemo.class) とします。
inheritance / dispatch

Q52. 出力は？

class Parent {
    int score = 10;
    String label() { return "P"; }
}
class Child extends Parent {
    int score = 20;
    String label() { return "C"; }
}
Parent p = new Child();
System.out.println(p.score + ":" + p.label());
A. 10:P
B. 10:C
C. 20:C
答え・解説
B。10:C。 フィールド参照は変数の宣言型Parentに基づきます。一方、オーバーライドされたインスタンスメソッドは実体型Childの実装が呼ばれます。
numeric / tracing

Q53. 出力は？

double result = 7 / 2;
System.out.println(result);
A. 3.0
B. 3.5
C. コンパイルエラー
答え・解説
A。3.0。 右辺の 7 / 2 はint同士なので先に整数除算されて3になります。その後doubleへ変換されます。
local variable / compile error

Q54. 次のコードはコンパイルできる？

int x;
if (args.length > 0) {
    x = 1;
}
System.out.println(x);
A. できる。未代入なら0
B. できない
答え・解説
B。 ローカル変数にはフィールドのような自動初期化がありません。条件によってxへ代入されない経路があるため、「初期化されていない可能性がある」と判定されます。
constructor chain

Q55. 出力は？

class Root {
    Root() { System.out.print("R"); }
}
class Middle extends Root {
    Middle() { System.out.print("M"); }
}
class Leaf extends Middle {
    Leaf() { System.out.print("L"); }
}
new Leaf();
A. LMR
B. RML
C. RLM
答え・解説
B。RML。 各コンストラクタの先頭で暗黙に super() が呼ばれるため、最上位のRootからMiddle、Leafの順に初期化されます。
