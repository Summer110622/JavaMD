interface / static

Q116. 次のAppはコンパイルできる？

interface Util {
    static void ping() { System.out.print("P"); }
}
class App implements Util {
    void run() {
        ping();
    }
}
A. できる
B. できない
答え・解説
B。 interfaceのstaticメソッドは実装クラスへ継承されません。呼び出すなら Util.ping() のようにinterface名で指定します。
abstract / final

Q117. 次のクラス宣言は有効？

abstract final class Base {
    abstract void work();
}
A. 有効
B. コンパイルエラー
答え・解説
B。 abstractクラスはサブクラスで未実装部分を完成させる前提ですが、finalクラスは継承禁止です。この2つを同じクラスに指定できません。
private / override

Q118. 次のChildはコンパイルできる？

class Parent {
    private void show() { }
}
class Child extends Parent {
    @Override
    public void show() { }
}
A. できる
B. できない
答え・解説
B。 ParentのprivateメソッドはChildへ継承されないため、Child.show()はオーバーライドではありません。@Override があるのでコンパイルエラーです。
constructor / overload

Q119. 出力は？

class Box {
    Box(long n) { System.out.print("L"); }
    Box(Integer n) { System.out.print("I"); }
}
new Box(1);
A. L
B. I
C. 呼び出しが曖昧でコンパイルエラー
答え・解説
A。L。 intからlongへのプリミティブ拡大変換が、Integerへのボクシングより先に適用されるため Box(long) が選ばれます。
super / initialization order

Q120. 出力順は？

class A {
    A() { System.out.print("A"); }
}
class B extends A {
    int n = init();
    int init() { System.out.print("I"); return 1; }
    B() { System.out.print("B"); }
}
new B();
A. AIB
B. IAB
C. ABI
答え・解説
A。AIB。 サブクラス生成時は、まず親コンストラクタ、その後に子のインスタンスフィールド初期化、最後に子コンストラクタ本体の順で進みます。
static / null reference

Q121. 次のコードはどうなる？

class Counter {
    static int n = 7;
}
Counter c = null;
System.out.println(c.n);
A. 7
B. NullPointerException
C. コンパイルエラー
答え・解説
A。7。 staticフィールドはインスタンスではなくクラスに属します。インスタンス変数経由の記述は推奨されませんが、この式ではnullをデリファレンスせずstaticフィールドが参照されます。
Map / keySet

Q122. 出力は？

Map<String,Integer> m = new HashMap<>();
m.put("A", 1);
m.put("B", 2);
Set<String> keys = m.keySet();
keys.remove("A");
System.out.println(m.containsKey("A") + ":" + m.size());
A. true:2
B. false:1
C. false:2
答え・解説
B。false:1。 keySet() はMapと連動するビューです。そのビューからキーを削除すると、対応するMapエントリも削除されます。
TreeMap / order

Q123. 出力は？

TreeMap<Integer,String> m = new TreeMap<>();
m.put(3, "C");
m.put(1, "A");
m.put(2, "B");
System.out.println(m.firstKey() + ":" + m.lastKey());
A. 3:2
B. 1:3
C. 3:1
答え・解説
B。1:3。 TreeMapはキーを自然順序で管理します。firstKey()は最小キー、lastKey()は最大キーを返します。
HashSet / equals

Q124. 出力されるsizeは？

Set<String> s = new HashSet<>();
s.add(new String("A"));
s.add("A");
System.out.println(s.size());
A. 1
B. 2
C. 実装依存
答え・解説

Collections.sort

Q125. 出力は？

List<Integer> xs = new ArrayList<>(Arrays.asList(3, 1, 2));
Collections.sort(xs);
System.out.println(xs.get(0) + ":" + xs.get(2));
A. 3:2
B. 1:3
C. 1:2
答え・解説
B。1:3。 Collections.sort はList自体を自然順序で並べ替えます。結果は [1, 2, 3] です。
array / enhanced for

Q126. 出力は？

StringBuilder[] a = { new StringBuilder("A") };
for (StringBuilder s : a) {
    s.append("B");
}
System.out.println(a[0]);
A. A
B. AB
C. コンパイルエラー
答え・解説
B。AB。 拡張forの変数sは参照のコピーですが、同じStringBuilderオブジェクトを指しています。オブジェクト自体を変更すると配列からも変更が見えます。
for / tracing

Q127. countはいくつ？

int count = 0;
for (int i = 0, j = 4; i < j; i++, j--) {
    count++;
}
System.out.println(count);
A. 2
B. 3
C. 4
答え・解説
A。2。 条件成立は (i,j)=(0,4) と (1,3) の2回です。更新後に (2,2) となり i < j がfalseになります。
array / clone

Q128. 出力は？

int[] a = {1, 2};
int[] b = a.clone();
b[0] = 9;
System.out.println(a[0] + ":" + (a == b));
A. 9:true
B. 1:true
C. 1:false
答え・解説
C。1:false。 clone()は別の配列オブジェクトを作ります。プリミティブ要素は値としてコピーされるため、b[0]の変更はa[0]へ影響しません。
instanceof / array

Q129. 出力は？

Object o = new String[] { "A" };
System.out.println(o instanceof Object[]);
A. true
B. false
C. コンパイルエラー
答え・解説
A。true。 String[]は参照型配列でありObject[]のサブタイプです。変数の宣言型がObjectでも、instanceofは実行時の実体を確認します。
cast / runtime

Q130. 次のコードはどうなる？

Number n = Integer.valueOf(3);
Double d = (Double) n;
System.out.println(d);
A. 3.0と表示
B. コンパイルエラー
C. 実行時にClassCastException
答え・解説
C。 NumberからDoubleへのダウンキャストは構文上可能ですが、実体はIntegerです。キャストは実体の型を変換しないため実行時例外になります。
boolean / &

Q131. 出力は？

int n = 0;
boolean r = false & (++n > 0);
System.out.println(n + ":" + r);
A. 0:false
B. 1:false
C. 1:true
答え・解説
B。1:false。 booleanに対する単一の & は両辺を評価します。左辺がfalseでも右辺の++nは実行されます。&& との違いが重要です。
Thread / isAlive

Q132. 出力は？

public static void main(String[] args) throws Exception {
    Thread t = new Thread(() -> { });
    System.out.print(t.isAlive() + ":");
    t.start();
    t.join();
    System.out.println(t.isAlive());
}
A. false:false
B. true:false
C. false:true
答え・解説
A。false:false。 start前はまだスレッドが生存していません。join後は処理終了が保証されるため、その時点でもisAlive()はfalseです。
synchronized / null

Q133. 次のコードはどうなる？

Object lock = null;
synchronized (lock) {
    System.out.println("run");
}
A. runと表示
B. コンパイルエラー
C. 実行時にNullPointerException
答え・解説
C。 synchronizedブロックのロック式は参照型としてコンパイルできますが、実行時にnullのモニタを取得できないためNullPointerExceptionになります。
Thread.yield / compile error

Q134. 次のコードはコンパイルできる？

boolean yielded = Thread.yield();
A. できる
B. できない
答え・解説
B。 Thread.yield() の戻り値はvoidです。実行機会を他スレッドへ譲るヒントを出すメソッドですが、成功・失敗をbooleanでは返しません。
boolean / definite assignment

Q135. 次のコードはコンパイルできる？

int x;
boolean ok = false && ((x = 1) > 0);
System.out.println(x);
A. でき、1と表示
B. でき、0と表示
C. できない
答え・解説
C。 && は左辺がfalseなら右辺を評価しないため、xへの代入は実行されない可能性があります。ローカル変数xはprintln時点で確実に初期化済みとは判定されません。
