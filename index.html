JAVA FUNDAMENTALS

Javaの基礎を、
細かく・順番に。

「書き方を覚える」だけでなく、JVMでどう実行されるか、型がなぜ重要か、クラス設計をどう考えるかまで、初心者がつまずきやすい点を分解して説明します。

初心者向けコード例つき依存なしJava 17+ を想定

1. Javaとは

Javaは、ソースコードをいったん .class 形式のバイトコードへコンパイルし、そのバイトコードを JVM（Java Virtual Machine）が実行する言語です。

JDK

開発に必要なツール一式。コンパイラ javac や実行環境を含みます。

JVM

JavaバイトコードをOS・CPU上で実行する仮想マシンです。

JRE

Javaアプリを実行するための環境。近年はJDK配布物の中に実行環境が含まれる形が一般的です。

バイトコード

ソースと機械語の中間表現。JVMが環境差を吸収します。

重要: 「JavaはどのOSでも同じ機械語で動く」のではなく、「同じバイトコードを、それぞれのOS向けJVMが実行する」と理解すると正確です。

2. 環境と実行の流れ

JDKを入れる
Java 17 または 21 のLTSを選ぶと学習しやすいです。
ソースを書く
Hello.java を作成します。
コンパイル
javac Hello.java で Hello.class を生成します。
実行
java Hello としてJVMにクラスを読み込ませます。
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}

main はプログラムの入口です。public はJVMから呼び出せること、static はインスタンス生成前でも呼べること、void は戻り値を返さないことを意味します。

3. 基本構文

Javaでは文の末尾に ; を付けます。ブロックは { } で囲み、大小文字を区別します。

// 1行コメント
/* 複数行コメント */

int count = 3;          // 文
if (count > 0) {        // ブロック
    System.out.println(count);
}
よくあるミス: ファイル名と public class 名は一致させます。public class Main なら通常ファイル名は Main.java です。

4. 変数と型

Javaは静的型付けです。変数には「どの種類の値を入れるか」という型がコンパイル時に決まります。

型用途例
byte / short / int / long整数int age = 20;
float / double小数double rate = 1.25;
char1文字char grade = 'A';
boolean真偽値boolean ok = true;
String文字列String name = "Java";
int x = 10;
long y = x;          // widening: 安全に広い型へ

long big = 100L;
int small = (int) big; // narrowing: 明示的キャストが必要

var message = "hello"; // ローカル変数なら型推論も可能

プリミティブ型は値そのものを扱います。一方、String や自作クラスは参照型で、変数はオブジェクトへの参照を保持します。

5. 演算子

算術

+ - * / %

比較

== != < <= > >=

論理

&& || !

代入

= += -= *= /=

int a = 7;
int b = 2;
System.out.println(a / b);       // 3: int同士なので整数除算
System.out.println(a / 2.0);     // 3.5: doubleを含むので小数
String比較: 文字列の内容比較は通常 equals() を使います。== は参照が同じかを見るため、意味が異なります。

6. 条件分岐

int score = 78;

if (score >= 90) {
    System.out.println("A");
} else if (score >= 70) {
    System.out.println("B");
} else {
    System.out.println("C");
}
String role = "admin";
String label = switch (role) {
    case "admin" -> "管理者";
    case "member" -> "一般ユーザー";
    default -> "ゲスト";
};

switch 式は「条件ごとに値を返したい」場面で読みやすくなります。

7. 繰り返し

for (int i = 0; i < 3; i++) {
    System.out.println(i);
}

int n = 3;
while (n > 0) {
    System.out.println(n);
    n--;
}

String[] names = {"Aki", "Mio", "Ren"};
for (String name : names) {
    System.out.println(name);
}

break はループを終了し、continue はその周回の残りを飛ばして次へ進みます。

8. 配列とコレクション

配列は長さが固定です。要素数が増減するデータには List が便利です。

int[] scores = {80, 92, 75};
System.out.println(scores[0]); // 80

import java.util.ArrayList;
import java.util.List;

List<String> users = new ArrayList<>();
users.add("Alice");
users.add("Bob");
System.out.println(users.get(0));
List

順序あり・重複可。

Set

重複を持たせたくない集合。

Map

キーと値の組。辞書・ハッシュ表に相当。

Array

固定長で軽量。プリミティブ配列も作れます。

9. メソッド

static int add(int a, int b) {
    return a + b;
}

public static void main(String[] args) {
    int result = add(3, 5);
    System.out.println(result);
}

int add(int a, int b) では、先頭の int が戻り値の型、a と b が引数です。戻り値が不要なら void を使います。

同じ名前で引数の型や個数が異なるメソッドを定義することをオーバーロードと呼びます。

10. クラスとオブジェクト

クラスは「データ」と「そのデータに対する振る舞い」をまとめた設計図です。

class User {
    private String name;
    private int age;

    User(String name, int age) { // コンストラクタ
        this.name = name;
        this.age = age;
    }

    void introduce() {
        System.out.println("私は" + name + "です");
    }
}

public class Main {
    public static void main(String[] args) {
        User user = new User("Aki", 20);
        user.introduce();
    }
}

new User(...) でインスタンスを生成します。this.name は「このインスタンス自身が持つフィールド」を表します。

11. 継承と interface

class Animal {
    void speak() {
        System.out.println("...");
    }
}

class Dog extends Animal {
    @Override
    void speak() {
        System.out.println("bow");
    }
}
interface Payable {
    void pay(int amount);
}

class CreditCard implements Payable {
    public void pay(int amount) {
        System.out.println(amount + "円を支払いました");
    }
}

継承は「is-a」の関係を表す場合に使います。再利用だけを目的に安易に継承すると結合が強くなるため、実務では委譲やinterfaceを組み合わせることが多いです。

12. アクセス修飾子と package

修飾子見える範囲
publicどこからでも
protected同一package + サブクラス
指定なし同一package
private同一クラス内のみ
package com.example.app;

public class UserService {
    private final UserRepository repository;

    public UserService(UserRepository repository) {
        this.repository = repository;
    }
}

package はクラスを名前空間として整理します。ディレクトリ構成とpackage名を対応させるのが基本です。

13. 例外処理

try {
    int value = Integer.parseInt("123");
    System.out.println(value);
} catch (NumberFormatException e) {
    System.out.println("数値に変換できません");
} finally {
    System.out.println("終了処理");
}

例外は「通常の戻り値では扱いにくい異常状態」を伝える仕組みです。例外には大きく、コンパイル時に処理を要求される checked exception と、実行時例外を中心とする unchecked exception があります。

設計の考え方: 例外を握りつぶすのではなく、「どこで回復するか」「どこまで上位へ伝えるか」を決めます。

14. ジェネリクス

List<String> names = new ArrayList<>();
names.add("Aki");

class Box<T> {
    private T value;

    void set(T value) { this.value = value; }
    T get() { return value; }
}

<T> は型を後から指定する仕組みです。キャストを減らし、型安全性を高めます。

15. ラムダ式と Stream

List<String> names = List.of("Alice", "Bob", "Ann");

names.stream()
    .filter(name -> name.startsWith("A"))
    .map(String::toUpperCase)
    .forEach(System.out::println);

Streamはコレクションそのものを変更する機能ではなく、「要素の流れに対して処理をつなぐ」APIです。filter は絞り込み、map は変換、forEach は終端処理です。

16. 初心者がつまずきやすいポイント

== と equals()

参照型の内容比較では目的に応じて equals() を使います。

null

参照先がない状態。アクセスすると NullPointerException の原因になります。

整数除算

5 / 2 は 2。小数が必要なら片方を double にします。

スコープ

{ } の内側で宣言した変数は、外側から使えない場合があります。
