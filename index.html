8. Set — HashSet / LinkedHashSet / TreeSet

実装順序検索用途

LinkedHashSet挿入順平均O(1)順番を保つ重複排除
TreeSetソート順O(log n)範囲・最小最大
TreeSet
TreeSet<Integer> set = new TreeSet<>();
set.addAll(List.of(30, 10, 20));

set.first();      // 10
set.last();       // 30
set.lower(20);    // 10
set.higher(20);   // 30
set.ceiling(15);  // 20
set.subSet(10, true, 30, false); // [10, 20]

15. スレッド — 初心者はまずこれだけ

スレッドは「プログラムの中で処理を進める流れ」です。最初から難しいロックや並行コレクションを覚える必要はありません。まず Threadを作る → startする → 少し待つ → 終了を待つ という流れを理解します。

やる処理を書く
Runnable やラムダ式で処理を用意します。
Threadを作る
new Thread(...) でスレッドオブジェクトを作ります。
start()する
新しいスレッドで処理が始まります。
必要ならjoin()する
そのスレッドが終わるまで待ちます。

いちばん簡単な例

Thread + ラムダ式
public class Main {
    public static void main(String[] args) throws InterruptedException {
        Thread worker = new Thread(() -> {
            System.out.println("別スレッドで実行中");
        });

        worker.start();
        worker.join();

        System.out.println("終了");
    }
}

最初に覚える6つのThread API

start()新しいスレッドを開始します。初心者が最初に覚える最重要API。
sleep(ms)現在動いているスレッドを指定時間だけ休ませます。
join()対象スレッドが終了するまで現在のスレッドを待たせます。
getName()スレッド名を取得します。
setName()スレッドに分かりやすい名前を付けます。
currentThread()今このコードを実行しているThreadを取得します。

sleep()

1秒ごとに表示
for (int i = 1; i <= 3; i++) {
    System.out.println(i);
    Thread.sleep(1000); // 1000ms = 1秒
}

スレッド名を見る

getName / currentThread
Thread worker = new Thread(() -> {
    Thread current = Thread.currentThread();
    System.out.println(current.getName());
});

worker.setName("worker-1");
worker.start();

start() と run() は違う

呼び方何が起きる?
thread.start()新しいスレッドを作り、その中でrun()が呼ばれる
thread.run()普通のメソッド呼び出し。新しいスレッドは作られない
初心者向けルール: 「別スレッドで動かしたい」なら run() ではなく start()。

Runnable とは?

Runnable
Runnable task = () -> {
    System.out.println("仕事をする");
};

Thread thread = new Thread(task);
thread.start();

Runnable は「実行したい処理」を表します。ラムダ式と相性がよく、new Thread(() -> {...}) と短く書けます。

2つ同時に動かす

2 threads
Thread a = new Thread(() -> {
    for (int i = 0; i < 3; i++) {
        System.out.println("A: " + i);
    }
});

Thread b = new Thread(() -> {
    for (int i = 0; i < 3; i++) {
        System.out.println("B: " + i);
    }
});

a.start();
b.start();

a.join();
b.join();
ポイント: AとBの表示順は毎回同じとは限りません。これが並行実行を理解する最初の重要ポイントです。

今は後回しでOK

synchronized、Lock、volatile、AtomicInteger、ExecutorService、CompletableFuture などは、Thread / Runnable / start / sleep / join に慣れてから学べば十分です。

学習順: Runnable → new Thread → start → sleep → join → currentThread/getName → 共有データの問題 → ExecutorService。
