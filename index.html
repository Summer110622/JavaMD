11. ラムダ式

ラムダとメソッド参照
Predicate<String> isLong = s -> s.length() >= 5;
Function<String, Integer> len = String::length;
Consumer<String> print = System.out::println;
Supplier<UUID> uuid = UUID::randomUUID;
effectively final: ラムダから参照するローカル変数は初期化後に再代入しません。

13. Stream API

filter → map → toList
List<String> result = names.stream()
    .filter(s -> !s.isBlank())
    .map(String::trim)
    .map(String::toUpperCase)
    .distinct()
    .sorted()
    .toList();
groupingBy
Map<Integer, List<String>> byLength = names.stream()
    .collect(Collectors.groupingBy(String::length));

15. スレッド — 初心者はまずこれだけ

まず Threadを作る → startする → 必要ならjoinする を覚えます。

Thread + ラムダ式
Thread worker = new Thread(() -> {
    System.out.println("別スレッドで実行中");
});
worker.start();
worker.join();
start()新しいスレッドを開始
sleep(ms)現在のスレッドを休ませる
join()対象スレッドの終了を待つ
getName()スレッド名を取得
setName()スレッド名を設定
currentThread()現在のThreadを取得
start() と run() は違う: 新しいスレッドで動かすなら start()。
