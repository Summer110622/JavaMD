interface / default / inheritance

Q176. 出力は？

interface Named {
    default String name() { return "I"; }
}
class Base {
    public String name() { return "B"; }
}
class Child extends Base implements Named { }
System.out.println(new Child().name());
A. I
B. B
C. defaultメソッド競合でコンパイルエラー
答え・解説
B。B。 interfaceのdefaultメソッドと継承したクラスのインスタンスメソッドが競合する場合、クラス側のメソッドが優先されます。
interface / field / compile error

Q177. 次のBothはコンパイルできる？

interface Left  { int CODE = 1; }
interface Right { int CODE = 2; }
class Both implements Left, Right {
    int value() { return CODE; }
}
A. でき、1を返す
B. でき、2を返す
C. できない
答え・解説
C。 両interfaceから同名の定数CODEが見えるため単純名では曖昧です。Left.CODEやRight.CODEのように修飾する必要があります。
modifier / abstract / static

Q178. 次の宣言は有効？

abstract class Worker {
    static abstract void run();
}
A. 有効
B. 無効でコンパイルエラー
答え・解説
B。 abstractはサブクラスでのオーバーライドを前提としますが、staticメソッドはオーバーライドではなく隠蔽の対象です。両者を同じメソッドに指定できません。
constructor / super / access

Q179. 次のChildはコンパイルできる？

class Parent {
    private Parent() { }
}
class Child extends Parent {
    Child() { }
}
A. できる
B. できない
答え・解説
B。 Child()には暗黙のsuper()が入りますが、Parentの引数なしコンストラクタはprivateなのでサブクラスから呼べません。
static / initializer / constructor

Q180. 出力は？

class Demo {
    static { System.out.print("S"); }
    { System.out.print("I"); }
    Demo() { System.out.print("C"); }
}
new Demo();
new Demo();
A. SICSIC
B. SICIC
C. ICIC
答え・解説
B。SICIC。 static初期化ブロックはクラス初期化時に1回だけ実行されます。インスタンス初期化ブロックとコンストラクタはオブジェクト生成ごとに実行されます。
this / shadowing

Q181. 出力は？

class Box {
    int n = 5;
    Box(int n) {
        n = n + 1;
    }
}
System.out.println(new Box(9).n);
A. 5
B. 9
C. 10
答え・解説
A。5。 コンストラクタ引数nがフィールド名を隠しています。代入しているのはローカルの引数であり、フィールドを変更するならthis.n = ...と書きます。

List / subList

Q183. 出力は？

List<Integer> xs = new ArrayList<>(Arrays.asList(1, 2, 3, 4));
List<Integer> mid = xs.subList(1, 3);
mid.set(0, 9);

TreeSet / navigation

Q184. 出力は？

TreeSet<Integer> s = new TreeSet<>(Arrays.asList(10, 20, 30));

Map / remove

Q185. 出力は？

Map<String,Integer> m = new HashMap<>();
m.put("A", 1);
boolean x = m.remove("A", 2);
boolean y = m.remove("A", 1);
System.out.println(x + ":" + y + ":" + m.size());
A. false:true:0
B. true:true:0
C. false:false:1
答え・解説
A。false:true:0。 2引数のremoveはkeyとvalueの両方が一致した場合だけ削除します。最初は値が違うのでfalse、次は削除できてtrueです。
2次元配列 / clone

Q186. 出力は？

int[][] a = { {1}, {2} };
int[][] b = a.clone();
b[0][0] = 9;
System.out.println(a[0][0] + ":" + (a == b) + ":" + (a[0] == b[0]));
A. 1:false:false
B. 9:false:true
C. 9:true:true
答え・解説
B。9:false:true。 2次元配列のclone()で複製されるのは外側配列です。内側配列への参照は共有されるため、内側要素の変更は両方から見えます。
array / Arrays.fill

Q187. 出力は？

int[] a = {1, 2, 3, 4};
Arrays.fill(a, 1, 3, 9);
System.out.println(Arrays.toString(a));
A. [1, 9, 9, 4]
B. [1, 9, 9, 9]
C. [9, 9, 3, 4]
答え・解説
A。[1, 9, 9, 4]。 範囲指定のArrays.fillは開始indexを含み、終了indexを含みません。この場合はindex 1と2だけが9になります。
for / code trace

Q188. sumはいくつ？

int sum = 0;
for (int i = 0, j = 4; i < j; i++, j--) {
    sum += i + j;
}
System.out.println(sum);
A. 4
B. 8
C. 12
答え・解説
B。8。 反復は(i,j)=(0,4)と(1,3)の2回です。それぞれ4を加算し、次の(2,2)では条件がfalseになります。
instanceof / short circuit / cast

Q189. 出力は？

Object o = null;
boolean ok = o instanceof String
    && ((String) o).length() > 0;

boolean / XOR

Q190. 出力は？

boolean a = true;

boolean / conditional operator

Q191. 次のコードはどうなる？

int n = 0;
int x = true ? 7 : 10 / n;
System.out.println(x);
A. 7と表示
B. ArithmeticException
C. コンパイルエラー
答え・解説
A。7。 条件演算子?:は選択された側だけを実行します。条件がtrueなので10 / nは評価されず、0除算は発生しません。
Thread / isInterrupted

Thread t = Thread.currentThread();

Thread / sleep / synchronized

Q193. t1がsleep中、t2は同じlockのsynchronizedブロックへ入れる？

Object lock = new Object();
Thread t1 = new Thread(() -> {
    synchronized (lock) {
        try { Thread.sleep(100); }
        catch (InterruptedException e) { }
    }
});
Thread t2 = new Thread(() -> {
    synchronized (lock) {
        System.out.print("B");
    }
});
A. sleepした瞬間に入れる
B. t1がsynchronizedブロックを抜けるまで入れない
C. sleepを使うとlock自体が無効になる
答え・解説
B。 Thread.sleep()は現在のスレッドを休止しますが、保持中のモニターロックを解放しません。同じlockを必要とするt2は待機します。
Thread / isAlive / join

Q194. 出力は？

public static void main(String[] args) throws Exception {
    Thread t = new Thread(() -> { });
    System.out.print(t.isAlive() + ":");
    t.start();
    t.join();
    System.out.println(t.isAlive());
}
A. false:false
B. false:true
C. true:false
答え・解説
A。false:false。 start前はまだ生存していません。join()から戻った時点では対象スレッドは終了済みなので、再びisAlive()はfalseです。
code trace / overload / numeric promotion

Q195. 出力は？

static void pick(int x)  { System.out.print("I"); }
static void pick(long x) { System.out.print("L"); }

byte b = 1;
pick(b);
A. I
B. L
C. 呼び出しが曖昧でコンパイルエラー
答え・解説
A。I。 byteはintにもlongにも拡大変換できますが、より近いint版が選択されます。算術やメソッド呼び出しでの基本型の昇格・拡大変換は頻出の確認点です。
