static

Q16. 次のコードはコンパイルできる？

class Box {
    int value = 10;
    static void show() {
        System.out.println(value);
    }
}
A. できる
B. できない
答え・解説
B。 staticメソッドから、特定のオブジェクトに属する非staticフィールドを直接参照することはできません。
static

Q17. 次の説明として正しいものは？

class Book {
    static String size = "A5";
    int pages = 100;
    void print() {
        System.out.println(size + " " + pages);
    }
}
A. print()からstatic変数sizeは参照できない
B. print()からsizeもpagesも参照できる
答え・解説
B。 非staticメソッドからは、staticメンバもインスタンスメンバも参照できます。
overload

Q18. このstaticメソッド定義は有効？

class Calc {
    static void f(int n) {}
    static void f(double n) {}
}
A. 有効
B. 重複定義でエラー
答え・解説
A。 引数の型が異なるためオーバーロードとして成立します。staticかどうかはオーバーロード可否の基準ではありません。
overload

Q19. 次の2メソッドはオーバーロードになる？

int g(int n) { return n; }
double g(int n) { return n; }
A. なる
B. ならず、コンパイルエラー
答え・解説
B。 引数の並びが同じです。戻り値の型だけを変えてもオーバーロードにはなりません。
interface

Q20. Cクラスが実装すべきメソッドは？

interface A { void a(); }
interface B extends A { void b(); }
class C implements B { }
A. b()だけ
B. a()だけ
C. a()とb()の両方
答え・解説
C。 BはAをextendsしているため、Bを実装する具象クラスはA由来とB自身の抽象メソッドの両方を実装する必要があります。
constructor

Q21. 自動生成されるコンストラクタについて正しいものは？

class Parent { Parent() {} }
class Child { }
A. Childには引数なしコンストラクタが自動生成される
B. コンストラクタは一切生成されない
答え・解説
A。 クラス内にコンストラクタが1つも明記されていない場合、引数なしのデフォルトコンストラクタが自動生成されます。
constructor

Q22. 次の説明として正しいものは？

class Parent {
    Parent() { System.out.println("P"); }
}
class Child extends Parent {
    Child() { System.out.println("C"); }
}
A. Child()の先頭では暗黙にsuper()が呼ばれる
B. super()は自動では呼ばれない
答え・解説
A。 明示的なthis(...)やsuper(...)がない場合、サブクラスのコンストラクタ先頭でsuper()が暗黙に呼ばれます。
enum

Q23. 次のコードはどうなる？

enum Color { RED, BLUE }
Color c = Color.GREEN;
A. 正常にコンパイル
B. コンパイルエラー
C. 実行時例外
答え・解説
B。 enum型には定義されている列挙定数だけを指定できます。GREENは存在しません。
HashMap

Q24. 次のコードで例外は発生する？

Map<Integer,String> map = new HashMap<>();
map.put(1, null);
System.out.println(map.get(1));
A. nullが表示される
B. put時に例外
C. get時に例外
答え・解説
A。 HashMapは値としてnullを保持できます。この例ではget(1)の結果としてnullが表示されます。
HashSet

Q25. 2回目のaddの戻り値は？

Set<String> s = new HashSet<>();
System.out.println(s.add("A"));
System.out.println(s.add("A"));
A. true, true
B. true, false
C. 2回目で例外
答え・解説
B。 最初は追加できるのでtrue。重複要素は保持されないため2回目はfalseです。
TreeSet

Q26. 出力は？

Set<Integer> s = new TreeSet<>();
s.add(30); s.add(10); s.add(20);
System.out.println(s);
A. [30, 10, 20]
B. [10, 20, 30]
C. 順序は保証されない
答え・解説
B。 TreeSetは自然順序で並びます。Integerなら小さい順です。
2次元配列

Q27. 出力は？

int[][] a = { {1}, {2, 3, 4} };
for (int[] row : a) {
    System.out.println(row.length);
}
A. 1, 3
B. 2, 2
C. コンパイルエラー
答え・解説
A。 Javaの2次元配列では各行の長さが同じである必要はありません。外側の拡張forでは各行のint[]を受け取ります。
for

Q28. sumはいくつ？

int[] a = {5, 10, 15, 20};
int sum = 0;
for (int i = 0; i < a.length; i += 2) {
    sum += a[i];
}
System.out.println(sum);
A. 15
B. 20
C. 50
答え・解説
B。20。 iは0→2と進むので、加算されるのはa[0]=5とa[2]=15です。
instanceof

Q29. 出力は？

interface Fly {}
class Bird implements Fly {}
class Sparrow extends Bird {}
Fly f = new Sparrow();
System.out.println(f instanceof Bird);
A. true
B. false
C. コンパイルエラー
答え・解説
A。 変数の宣言型がFlyでも、実体はSparrowです。SparrowはBirdのサブクラスなのでinstanceof Birdはtrueです。
cast

Q30. 正しいキャスト後のメソッド呼び出しはどれ？

Object o = new String("java");
A. (String)o.length()
B. ((String)o).length()
答え・解説
B。 先にo全体をStringへキャストしてからlength()を呼びます。ドット演算子はキャストより強く結び付くため、括弧が重要です。
synchronized

Q31. synchronizedを指定できる場所は？

A. メソッドだけ
B. ブロックだけ
C. メソッドとブロックの両方
答え・解説
C。 synchronizedはメソッド全体にも、メソッド内の特定ブロックにも指定できます。
Thread.yield

Q32. Thread.yield() の説明として最も適切なのは？

A. 現在のスレッドを必ず1秒停止する
B. 他のスレッドに実行の機会を与えるための呼び出し
C. スレッドを終了する
答え・解説
B。 yield()は他のスレッドへ実行機会を渡すために使われるAPIです。
Thread.sleep

Q33. Thread.sleep(500) は何をする？

A. 対象Threadオブジェクトを必ず終了する
B. 現在実行中のスレッドを指定時間停止させる
C. 新しいスレッドを開始する
答え・解説
B。 sleepは現在のスレッドを指定時間だけ停止させます。start()とは役割が異なります。
Runnable

Q34. 正しい説明はどれ？

A. Runnableはクラスなのでextendsする
B. Runnableはinterfaceなのでimplementsする
C. Runnableはenumである
答え・解説
B。 Runnableはinterfaceです。クラスがRunnableを実装する場合はimplementsを使います。
List

Q35. remove(int index) の戻り値は？

List<String> list = new ArrayList<>();
list.add("A"); list.add("B"); list.add("C");
String x = list.remove(1);
A. "A"
B. "B"
C. true
答え・解説
B。 remove(int index)は指定位置の要素を削除し、その削除された要素を返します。削除後は後続要素のインデックスが1つ前へ詰まります。
