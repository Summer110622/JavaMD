interface / default

Q136. 出力は？

interface Greeter {
    String label();
    default void greet() { System.out.print(label()); }
}
class App implements Greeter {
    public String label() { return "A"; }
}
new App().greet();
A. A
B. Greeter
C. コンパイルエラー
答え・解説
A。A。 defaultメソッドから抽象メソッドを呼べます。実行時にはAppが実装したlabel()が呼ばれます。
interface / multiple

Q137. 次のクラスCはコンパイルできる？

interface A { void run(); }
interface B { void run(); }
class C implements A, B {
    public void run() { }
}
A. できる
B. 同名メソッドが競合するのでできない
答え・解説
A。 同じシグネチャの抽象メソッドなら、Cの1つのpublic実装で両方のinterface契約を満たせます。defaultメソッド同士の競合とは異なります。
final / reference

Q138. 次のコードはコンパイルできる？

final List<String> xs = new ArrayList<>();
xs.add("A");
System.out.println(xs.size());
A. でき、1と表示
B. finalなのでadd時にコンパイルエラー
C. 実行時例外
答え・解説
A。 finalが禁止するのは変数xsへの再代入です。参照先のArrayList自体が変更可能ならadd()は実行できます。
constructor / overload

Q139. 次の呼び出しはどうなる？

class Box {
    Box(String s) { }
    Box(Integer n) { }
}
new Box(null);
A. Box(String)が選ばれる
B. Box(Integer)が選ばれる
C. 呼び出しが曖昧でコンパイルエラー
答え・解説
C。 nullはどちらの参照型にも渡せますが、StringとIntegerの間により具体的という関係がないため、最適なオーバーロードを1つに決められません。
static / initialization

Q140. 出力は？

class Sample {
    static { System.out.print("S"); }
    { System.out.print("I"); }
    Sample() { System.out.print("C"); }
}
new Sample();
new Sample();
A. SICSIC
B. SICIC
C. ICIC
答え・解説
B。SICIC。 static初期化子はクラス初期化時に1回だけ実行されます。インスタンス初期化子IとコンストラクタCはnewのたびに実行されます。
this / super

Q141. 出力は？

class Base { int n = 1; }
class Child extends Base {
    int n = 2;
    int sum() { return this.n + super.n; }
}
System.out.println(new Child().sum());
A. 2
B. 3
C. コンパイルエラー
答え・解説
B。3。 this.nはChild側の2、super.nはBase側の1を明示的に参照します。
Map / values view

Q142. 出力は？

Map<String,Integer> m = new HashMap<>();
m.put("A", 1);
m.put("B", 2);
Collection<Integer> values = m.values();
values.remove(1);
System.out.println(m.size() + ":" + m.containsKey("A"));
A. 2:true
B. 1:false
C. 1:true
答え・解説
B。1:false。 values()はMapと連動するビューです。ビューから値1を削除すると、その値に対応するエントリもMapから削除されます。
TreeSet / Comparator

Q143. 出力されるsizeは？

Set<String> s = new TreeSet<>(Comparator.comparingInt(String::length));
s.add("AA");
s.add("BB");
s.add("C");
System.out.println(s.size());
A. 2
B. 3
C. 実装依存
答え・解説
A。2。 TreeSetはComparatorの比較結果が0なら同一要素として扱います。"AA"と"BB"は長さが同じなので両方は保持されません。

List<String> xs = new ArrayList<>(Arrays.asList("A", "B", "C", "D"));

Map / remove

Q145. 出力は？

Map<String,Integer> m = new HashMap<>();
m.put("x", 1);
boolean a = m.remove("x", 2);
boolean b = m.remove("x", 1);
System.out.println(a + ":" + b + ":" + m.size());
A. false:true:0
B. true:true:0
C. false:false:1
答え・解説
A。 remove(key,value)はキーと値の両方が一致した場合だけ削除します。最初は値が違うのでfalse、次は一致してtrueです。
array / clone

Q146. 出力は？

StringBuilder[] a = { new StringBuilder("A") };

for / continue

Q147. 出力は？

int i = 0;
int sum = 0;
for (; i < 4; i++) {
    if (i % 2 == 0) continue;
    sum += i;
}
System.out.println(i + ":" + sum);
A. 3:4
B. 4:4
C. 4:6
答え・解説
B。4:4。 for文ではcontinueしても更新式i++へ進みます。加算されるのは1と3だけです。
switch / null

Q148. 次のコードはどうなる？

String s = null;
switch (s) {
    case "A": System.out.print("A"); break;
    default: System.out.print("D");
}
A. D
B. コンパイルエラー

C。 Stringのswitch自体は有効ですが、式がnullだとcase比較へ進む前にNullPointerExceptionになります。

for (int i = 0; i < 2; i++) {

cast / interface

Q152. 次のコードはどうなる？

class Box { }
interface Mark { }
Box b = new Box();
Mark m = (Mark) b;
System.out.println(m);
A. コンパイルエラー
B. 正常に実行
C. 実行時にClassCastException
答え・解説
C。 Boxはfinalではないためinterface型へのキャストはコンパイル可能ですが、実体のBoxはMarkを実装していないので実行時に失敗します。
boolean / non-short-circuit

Q153. 出力は？

int n = 0;
boolean r = false & (++n > 0);
System.out.println(n + ":" + r);
A. 0:false
B. 1:false
C. 1:true
答え・解説
B。1:false。 booleanの&は短絡評価しないため、左辺がfalseでも右辺の++nが評価されます。結果全体はfalseです。
Thread / run

Q154. 出力は？

Thread t = new Thread(() -> System.out.print("R"));
t.run();
t.run();
A. R
B. RR
C. 2回目でIllegalThreadStateException
答え・解説
B。RR。 run()を直接呼ぶのは通常のメソッド呼び出しなので、同じThreadオブジェクトでも複数回呼べます。start()の再実行とは異なります。
Thread / join / isAlive

Q155. 出力は？

public static void main(String[] args) throws Exception {
    Thread t = new Thread(() -> { });
    System.out.print(t.isAlive() + ":");
    t.start();
    t.join();
    System.out.print(t.isAlive());
}
A. false:false
B. false:true
C. true:false
答え・解説
A。false:false。 start前は未開始なのでfalseです。join()から戻る時点ではtは終了済みなので再びfalseです。
