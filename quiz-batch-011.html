interface / default / inheritance

Q216. 出力は？

interface Named {
    default String name() { return "I"; }
}
class Base {
    public String name() { return "B"; }
}
class Item extends Base implements Named { }

System.out.println(new Item().name());
A. I
B. B
C. コンパイルエラー
答え・解説
B。B。クラスから継承したインスタンスメソッドは、interfaceのdefaultメソッドより優先されます。Item側で明示的にオーバーライドしなくてもBase.name()が使われます。
abstract / final / compile error

Q217. 次のクラスはコンパイルできる？

abstract class Worker {
    abstract final void work();
}
A. できる
B. できない
答え・解説
B。abstractメソッドはサブクラスで実装されることを前提にしますが、finalメソッドはオーバーライドできません。両方を同時に指定できないためコンパイルエラーです。
protected / package / inheritance

Q218. Childのread()はコンパイルできる？

// p1/Base.java
package p1;
public class Base {
    protected int value = 5;
}

// p2/Child.java
package p2;
import p1.Base;
class Child extends Base {
    int read(Base other) {
        return other.value;
    }
}
A. でき、5を返す
B. できない
答え・解説
B。別packageのサブクラスからprotectedメンバへアクセスする場合、継承関係を通じた参照である必要があります。ここでotherの型はBaseなので、Childからother.valueを直接参照できません。
constructor / private / super

Q219. 次のChildはコンパイルできる？

class Parent {
    private Parent() { }
}
class Child extends Parent {
    Child() { }
}
A. できる
B. できない
答え・解説
B。Child()の先頭には暗黙のsuper()が入りますが、Parent()はprivateなのでChildから呼び出せません。利用可能なスーパークラスのコンストラクタが必要です。
this / constructor invocation

Q220. 次のBoxはコンパイルできる？

class Box {
    int size = 3;

    Box() {
        this(size);
    }

    Box(int n) { }
}
A. できる
B. できない
答え・解説
B。this(...)やsuper(...)の引数を評価する段階では、まだ現在のインスタンスを参照できません。インスタンスフィールドsizeをthis(size)の引数に使うためコンパイルエラーです。
static / overload / null

Q221. 次の呼び出しはどうなる？

class Printer {
    static void show(String s) { }
    static void show(Integer n) { }

    static void test() {
        show(null);
    }
}
A. String版が呼ばれる
B. Integer版が呼ばれる
C. コンパイルエラー
答え・解説
C。nullはStringにもIntegerにも代入できますが、StringとIntegerには継承関係がなく、どちらのオーバーロードがより適切か決められません。そのため呼び出しが曖昧になります。
Map / keySet view

Q222. 出力は？

Map<String,Integer> map = new HashMap<>();
map.put("A", 1);
map.put("B", 2);

Set<String> keys = map.keySet();
keys.remove("A");

System.out.println(map.containsKey("A") + ":" + map.size());
A. true:2
B. false:1
C. false:2
答え・解説
B。false:1。keySet()はコピーではなくMapに結び付いたビューです。ビューからkeyを削除すると、対応するMapのエントリも削除されます。
TreeSet / pollFirst

Q223. 出力は？

TreeSet<Integer> set = new TreeSet<>();
set.add(4);
set.add(1);
set.add(3);

System.out.println(set.pollFirst() + ":" + set.first());
A. 1:3
B. 1:1
C. 4:3
答え・解説
A。1:3。pollFirst()は最小要素を取得すると同時に集合から削除します。その後の最小要素は3なのでfirst()は3を返します。
List / subList view

Q224. 出力は？

List<String> xs =
    new ArrayList<>(Arrays.asList("A", "B", "C", "D"));

xs.subList(1, 3).clear();
System.out.println(xs);
A. [A, D]
B. [A, B, C, D]
C. [B, C]
答え・解説
A。[A, D]。subList(1, 3)は元ListのBとCに対応するビューです。そのビューをclear()すると、元のListからもBとCが削除されます。
Map / replace

Q225. 出力は？

Map<String,Integer> map = new HashMap<>();
map.put("x", 1);

boolean a = map.replace("x", 2, 3);
boolean b = map.replace("x", 1, 4);

System.out.println(a + ":" + b + ":" + map.get("x"));
A. false:true:4
B. true:true:4
C. false:false:1
答え・解説
A。false:true:4。3引数のreplaceは、現在値が指定した旧値と一致するときだけ置換します。最初は不一致、2回目は1と一致するため4へ更新されます。
2次元配列 / null / runtime

Q226. 次のコードはどうなる？

int[][] table = new int[2][];
table[0] = new int[] {1, 2};

int total = 0;
for (int[] row : table) {
    total += row.length;
}
System.out.println(total);
A. 2と表示
B. 0と表示
C. NullPointerException
答え・解説
C。table[1]は内側配列を作っていないためnullです。2回目の反復でrow.lengthを評価するとNullPointerExceptionが発生します。
loop / labeled break / trace

Q227. 出力は？

int total = 0;

outer:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (i + j == 4) {
            break outer;
        }
        total += i * j;
    }
}
System.out.println(total);
A. 3
B. 6
C. 18
答え・解説
A。3。i=1ではj=1で1、j=2で2を加えてtotalは3になります。j=3でi+jが4となり、ラベル付きbreakで外側のループまで終了します。
array / initializer / compile error

Q228. 次の配列宣言はコンパイルできる？

int[] values = new int[2] {10, 20};
A. できる
B. できない
答え・解説
B。配列生成時に要素を初期化するならnew int[] {10, 20}のように長さを省略します。new int[2]と初期化子を同時には指定できません。
cast / array covariance / runtime

Q229. 次のコードはどうなる？

Object[] values = new String[1];
values[0] = Integer.valueOf(7);
System.out.println(values[0]);
A. 7と表示
B. コンパイルエラー
C. ArrayStoreException
答え・解説
C。String[]はObject[]へ代入できますが、実体の配列型はString[]のままです。Integerを格納しようとした時点で実行時にArrayStoreExceptionが発生します。
boolean / & / evaluation

Q230. 出力は？

int n = 0;
boolean result = false & (++n > 0);
System.out.println(n + ":" + result);
A. 0:false
B. 1:false
C. 1:true
答え・解説
B。1:false。booleanに対する単一の&は両辺を必ず評価します。左辺がfalseでも++nが実行されるためnは1になります。
instanceof / interface / non-final class

Q231. 次のコードはどうなる？

class Box { }

Box box = new Box();
System.out.println(box instanceof Runnable);
A. falseと表示
B. trueと表示
C. コンパイルエラー
答え・解説

Thread / synchronized / lock

Q232. 次の説明として正しいものは？

class Gate {
    synchronized void enter() {
        // shared work
    }
}

Gate a = new Gate();
Gate b = new Gate();
A. a.enter()とb.enter()は必ず同じロックで排他される
B. aとbは別インスタンスなので、2つのenter()は同時実行され得る
C. synchronizedを付けるとインスタンス生成が1個に制限される
答え・解説
B。通常のsynchronizedインスタンスメソッドが使うロックはthisです。aとbは別オブジェクトなのでロックも別であり、異なるスレッドから同時にenter()へ入ることができます。
Thread / run / start / join

Q233. 出力は？

public static void main(String[] args) throws Exception {
    Runnable job = () -> System.out.print("X");
    Thread t = new Thread(job);

    t.run();
    t.start();
    t.join();
}
A. X
B. XX
C. 実行時例外
答え・解説
B。XX。t.run()は現在のスレッドで通常のメソッドとして1回実行されます。その後t.start()で新しいスレッドからrun()がもう1回実行され、join()で終了を待ちます。
Thread / currentThread

Q234. 出力は？

public static void main(String[] args) throws Exception {
    Thread t = new Thread() {
        public void run() {
            System.out.print(Thread.currentThread() == this);
        }
    };
    t.start();
    t.join();
}
A. true
B. false
C. コンパイルエラー
答え・解説
A。true。start()によってこのThreadオブジェクト自身が新しい実行スレッドになります。run()内のThread.currentThread()と、この匿名Threadクラスのthisは同じオブジェクトです。
Generics / wildcard / compile error

Q235. 次のコードはコンパイルできる？

List<? extends Number> nums = new ArrayList<Integer>();
nums.add(Integer.valueOf(1));
A. できる
B. できない
答え・解説
B。? extends Numberの実際の要素型はIntegerとは限らないため、null以外の値を安全に追加できません。Numberとして読み取ることはできますが、このaddはコンパイルエラーです。
